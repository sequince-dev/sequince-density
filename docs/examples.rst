Examples
========

The `sequince-examples repository
<https://github.com/sequince-dev/sequince-examples>`_ and its
`documentation
<https://sequince.readthedocs.io/projects/sequince-examples/en/latest/>`_
contain worked examples highlighting different features in Sequince.

The pages on :doc:`normalizing_flows`, :doc:`gaussian_mixtures`, and
:doc:`proposals` contain short usage examples for ``sequince-density``.
