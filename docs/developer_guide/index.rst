Developer guide
===============

These guidelines describe how to contribute to ``sequince-density`` and the
responsibilities that apply to contributions.

* The :doc:`contribution guidelines <CONTRIBUTING>` cover development setup,
  code style, typing, validation, documentation, and the pull request process.
* The `Sequince AI policy
  <https://github.com/sequince-dev/sequince/blob/main/AI_POLICY.md>`_
  explains contributor ownership, review expectations, and validation of
  AI-assisted work. This policy also applies to ``sequince-density``.
